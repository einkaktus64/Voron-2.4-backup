# 🚀 Voron 2.4 Klipper-Backup 💾

> Ein zuverlässiges Backup-Skript für manuelle oder vollautomatisierte GitHub-Backups deiner Klipper-Konfiguration.

---

## 📖 Über dieses Repository

Hier liegen die aktuellen Sicherungen für meinen **Voron 2.4** 3D-Drucker. Damit ist die Drucker-Konfiguration sicher in der Cloud gespeichert und kann jederzeit wiederhergestellt werden, falls mal etwas schiefgeht.

## ✨ Highlights
* 🔄 **Automatisiert:** Regelmäßige Backups der Klipper-Configs direkt zu GitHub.
* 🛠️ **Manuell:** Jederzeit speicherbar (z.B. nach wichtigen Änderungen an der `printer.cfg`).
* 🛡️ **Sicher:** Kein Verlust von Makros, Kalibrierungsdaten oder Netzwerkeinstellungen mehr.
